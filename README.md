# User Service

Консольное CRUD-приложение на Java с использованием Hibernate и PostgreSQL.

## 🚀 Функциональность
- Создание, чтение, обновление и удаление пользователей.
- Валидация полей: имя (3–50 символов, только буквы, не более 3 пробелов), email (до 50 символов, латиница, @, ., -, _, домены .com/.ru), возраст (10–80, опционально).
- Автоматическое проставление даты создания (created_at).
- Логирование (SLF4J + Log4j2).
- DAO-паттерн.
- Транзакционность.

## 🛠️ Технологии
- Java 11
- Hibernate 5.6
- PostgreSQL
- Maven
- SLF4J + Log4j2
